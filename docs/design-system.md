# 设计系统

本文件是视觉实现的单一事实源。改颜色、圆角、间距、字体前先改这里，再改 `src/styles/tokens.css`。

## 1. 设计原则

1. **一个物体在动，而不是两个页面在切换。** 封面、播放页、dock 是同一套“胶囊壳”语言的不同尺寸。
2. **品牌红只做强调，不做大面积背景。** 大面积由近黑/近白的中性表面承载，红色出现在当前状态、主操作、喜欢、VIP/音质徽标和流体环境光里。
3. **玻璃只压在静态层上。** 滚动列表里不用 `backdrop-filter`；玻璃用于 dock、命令面板、播放页顶栏和队列抽屉。
4. **封面是唯一不受控的内容。** 封面上的文字用固定白色 + 暗色渐变保证可读；不要把主题的 `onSurface` 压到封面上。
5. **桌面不是放大的手机。** 信息密度、鼠标 hover、键盘、右键菜单、表格、原生标题栏都是设计的一部分。

### 封面取色

- 只在**播放语境**启用：dock、沉浸播放页、当前曲目强调。
- 从当前曲目 palette 派生 `--accent` / `--accent-2` / `--accent-3`。
- 列表页、搜索页、设置页保持中性表面，避免整页随封面变色导致阅读疲劳。
- 浅色主题下环境光降低透明度，避免变成“彩色纸”。
- 灰阶封面回落到中性灰，不强行染色。

## 3. 字体

| 角色 | 字体 | 字号 | 字重 | 用途 |
|---|---|---|---|---|
| Display | Inter | 44–48px | 700 | 沉浸播放页标题 |
| Page title | Inter + 系统中文 | 28–34px | 700 | 页面大标题 |
| Section | Inter + 系统中文 | 15px | 650 | 区块标题 |
| Body | Inter + 系统中文 | 13px | 400/500 | 正文、列表 |
| Label | Inter + 系统中文 | 11–12px | 500/600 | 控件、行标题 |
| Caption | Inter + 系统中文 | 9.5–10.5px | 400/500 | 时间、辅助信息 |
| Eyebrow | Inter | 9.5px | 650 | 大写小标签，字距 0.16em |

- 中文使用 `Microsoft YaHei UI`（Windows 自带），macOS 回落 `PingFang SC`，Linux 回落 `Noto Sans SC`。
- 数字使用 `font-variant-numeric: tabular-nums`，时间、时长、序号必须对齐。
- 不使用 8px 以下的字；徽标最小 7.5px 且只用于大写拉丁缩写。

## 5. 间距与布局

### 桌面布局

| 区域 | 尺寸 |
|---|---:|
| 标题栏 | 48px |
| 左侧栏 | 248px（折叠 76px） |

### 响应式

| 宽度 | 行为 |
|---|---|
| ≥1240 | 三栏完整 |
| 1120–1240 | 右栏 300px，内容密度略降 |
| <1120 | 右栏隐藏，内容两栏 |
| <900 | 侧栏图标化，播放页纵向堆叠 |
| <720 | 侧栏隐藏，dock 简化 |

断点不是“手机版”；即使在最窄的桌面窗口，也保持可读的表格与键盘操作。

## 6. 组件

### 标题栏

- 左侧：品牌 mark + `Decro` + `DESKTOP`。
- 中间：全局搜索触发器（Ctrl/Cmd K）。
- 右侧：主题切换、设置、窗口控制。
- 可拖拽区域使用 `data-tauri-drag-region`；按钮区域不拖拽。

### 侧栏

- 主导航：主页 / 分类 / 资料库 / 搜索。
- “我的音乐”：喜欢、每日推荐、最近播放。
- 歌单列表：缩略封面 28px + 标题 + 副标题。
- 底部：账号、折叠按钮。
- 折叠后只保留图标；不显示歌单列表。

### 卡片

- 封面 1:1，圆角 12px。
- hover：整卡上移 3px，封面 scale 1.035，播放按钮从下方浮现。
- 卡面左上角类型徽标：PLAYLIST / RADAR / CHART，使用半透明黑底 + 白色细边框。
- 标题最多一行，副标题最多一行。

### 曲目表格

- 列：序号 / 标题（封面 34 + 标题 + 艺人）/ 专辑 / 音质 / 时长 / 操作。
- 行高 52px；hover 显示播放按钮与操作，隐藏序号。
- 当前曲目使用 primary 淡底 + primary 标题。
- 双击整行播放；键盘 Enter 播放（后续）。

### 底部 dock

- 胶囊 22px，玻璃底，1px 高光，阴影。
- 左：封面 54px + 标题/艺人 142px。
- 中：传输控制 + 进度（时间 + 2px 轨道）。
- 右：喜欢、歌词、队列、音量、展开。
- 点击封面/标题/展开进入沉浸播放页。
- 播放页打开时 dock 以 200ms 下沉淡出。

### 沉浸播放页

- 覆盖标题栏以下区域；保留窗口控制。
- 左侧大封面（最大 430px，22px 圆角，阴影），右侧标题 32–48px + 歌词 + 动作胶囊。
- 背景：封面取色径向渐变 + 三个慢速 blob + 细颗粒。
- 底部：全宽进度 + 左右时间；中间传输；右侧音量/队列。
- 队列抽屉从右侧滑入，玻璃底。

### 设置

- 左侧 170px 锚点导航；右侧最大 800px 卡片。
- 行高 54px，标签 + 说明 + 控件。
- 开关 34×20，滑块使用 primary。

## 7. 封面生成

为了在不引入外部图片的情况下保持视觉丰富，原型使用 `CoverArt`：

- 4 个颜色：`--c1` 深底、`--c2` 主色、`--c3` 亮色、`--c4` 暗部。
- 线性渐变 + 径向渐变 + 2–3 个有机 blob（`border-radius` 不规则）。
- 叠加细颗粒（内联 SVG turbulence）+ 轻微 soft-light。
- 左下角 `DECRO` 字标与细线，只有部分场景显示。
- 10 个 seed 变体改变 blob 位置/形状，避免卡片重复感。

真实接入封面后，保留同样的“颜色洗 + 暗角 + 颗粒”处理，而不是直接铺原图。

## 8. 可访问性

- 正文与背景对比度不低于 4.5:1；次要文字不低于 3:1。
- 所有图标按钮有 `aria-label`；可切换控件使用 `role="switch"` 或 `aria-pressed`。
- 键盘焦点使用 2px primary outline，offset 2px。
- `prefers-reduced-motion` 下动效退化为 fade；不隐藏信息。
- 支持系统深浅色；不强制主题。

## 9. alpha42 真机校正（2026-11-08）

真机截图（`docs/screenshots/apk/`）显示实际 UI 与公开源码的 Android 设计线并不完全相同。以下修正优先于前文的旧假设：

- **画布纯黑**：`#000`，不是 `#121417`；卡片接近 `#1B1C1E`。
- **大标题**：主页/资料库/搜索使用超大左对齐标题（视觉约 30sp，桌面映射为 34–44px）。
- **首页**：两张大幅推荐卡（每日推荐 / 私人雷达）+ 横向大卡货架 + 双列曲目行；没有小型 5 列卡片网格。
- **资料库**：源设计为 5 条整行入口（喜爱歌曲/播放列表/艺人/专辑/歌曲），红色图标 + 右侧 chevron；当前实现只保留已接线的 3 条（喜爱/歌单/最近）。
- **搜索**：未聚焦时只有一个胶囊输入；聚焦后输入置顶、红色 X、`Cloud Music / 资料库` 分段、建议与圆角结果卡。
- **详情**：全屏模糊封面，没有清晰方形封面；标题/日期居中；巨大白色圆角矩形播放键；曲目是玻璃圆角行。
- **播放器**：封面有斜向玻璃反光；喜欢是**星标**；进度是**波形**；播放键是**白色圆角矩形**；底部是评论/输出/队列。
- **歌词**：独立全屏模式，封面消失；当前行大号白色粗体，翻译小一号。
- **迷你播放器**：单行胶囊 + 封面 + 标题/艺人 + 播放/下一首 + 底部红色进度线。
- **颜色**：红色只做图标、进度、星标和状态强调；大面积是黑/白/灰。
- **桌面化**：左侧图标栏替代底部 4 图标；播放页两栏；歌词模式全宽；内容宽度限制在 980–1320px。

新增 token：

```css
--r-feature: 26px;   /* 首页大幅推荐卡 */
--bg: #000;          /* 深色画布 */
--surface-container: #1b1c1e;
--on-surface: #f5f5f7;
--on-surface-3: #8e8e93;
```

旧的 22/16/12/8/28 形状令牌仍用于 dock、普通卡、chip、纸面；不冲突。

### 设置页（alpha42）

- 全宽「账户与设置」sheet，顶部 sticky：左侧红色 X 圆钮、居中标题。
- 账户卡：头像 + 昵称 + 数字 ID。
- 分组标签：个性化 / 歌词 / 实验；每组由独立圆角行卡组成。未接线的音频/模型行不展示。
- 行：标题 + 说明 + 右侧控件（大号红色开关 / 值 + 上下 chevron / 右箭头）。
- 退出登录是单独的红色文字行，不做主按钮。
