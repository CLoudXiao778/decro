# 桌面适配

## 1. 目标

保留 Cirro 的材质与动效，但按桌面的信息密度和操作方式重排。判断标准：

- 1440×900 下，一眼看到“探索 / 正在播放 / 音乐库”三块信息，而不是一条被拉长的手机列表。
- 鼠标 hover、右键、键盘、拖拽是主要操作；触控手势是补充。
- 窗口可以任意缩放；最小 960×640 仍然可用。
- 不是把 390px 的手机 UI 居中放大，也不是简单加一个左侧栏。

## 2. 三栏结构

```text
┌─────────────────────────────────────────────────────────────────────┐
│ 标题栏：品牌 / 搜索 / 主题 / 设置 / 窗口控制                         │
├──────────────┬──────────────────────────────────┬───────────────────┤
│ 侧栏 248px    │ 主内容                            │ 正在播放 332px     │
│ 探索/搜索/库  │ 首页 / 搜索 / 详情 / 设置          │ 封面 / 歌词 / 队列  │
│ 我的音乐      │                                  │                   │
│ 歌单列表      │                                  │                   │
│ 账号          │                                  │                   │
├──────────────┴──────────────────────────────────┴───────────────────┤
│ 底部浮岛 dock：封面 / 标题 / 控制 / 进度 / 音量 / 展开               │
└─────────────────────────────────────────────────────────────────────┘
```

### 为什么不是底部 tab

手机的底部三 tab 在桌面上会浪费横向空间，并让“当前在哪”难以扫读。左侧栏可以同时容纳导航、音乐库和歌单，符合桌面音乐播放器的习惯。底部 dock 保留 Cirro 的胶囊形态，承担“随时可播放”的持续入口。

### 为什么保留右侧播放栏

手机播放页是“全屏覆盖”；桌面可以同时看内容与歌词。右侧栏承担“常驻的轻量播放语境”，沉浸播放页承担“专注听歌”的语境。两者共用同一份播放状态与封面。

## 3. 三种播放形态

| 形态 | 触发 | 尺寸 | 作用 |
|---|---|---|---|
| 底部 dock | 默认 | 72px 高胶囊 | 控制、进度、快速喜欢、展开 |
| 右侧播放栏 | 宽屏常驻 | 332px | 封面、歌词预览、队列、信息 |
| 沉浸播放页 | 点击 dock / 右侧栏 / L | 覆盖标题栏以下 | 大封面、完整歌词、队列抽屉 |
| 迷你播放器 | 标题栏按钮 / `?mini` | 420×128 | 置顶小窗；Tauri 独立窗口待接入 |

## 4. 内容页

### 探索

- 大 hero + 私人雷达双卡；
- 5 列推荐卡（窄屏 4/3/2）；
- 最近播放 + 新歌速递并排；
- 雷达/场景 3 列；
- 榜单 3 列。

### 搜索

- 标题栏全局搜索 + 命令面板（Ctrl/Cmd K）；
- 搜索页内也可以输入；热门/历史/分类；
- 结果按单曲/歌单分组，支持 tab 过滤。

### 详情

- 大封面 + 标题 + 作者 + 描述 + 统计 + 操作；
- 曲目表格：序号 / 标题 / 专辑 / 音质 / 时长 / 操作；
- 相关歌单。

### 音乐库

- 喜欢 / 歌单 / 专辑 / 歌手 / 最近播放；
- 歌单网格、专辑网格、歌手圆头像；
- 后续加多选、拖拽排序、右键菜单。

## 5. 桌面交互

| 交互 | 行为 |
|---|---|
| hover 卡片 | 抬升 + 播放按钮浮现 |
| 双击曲目行 | 播放 |
| 右键 | 上下文菜单（后续） |
| 拖动曲目 | 加入队列/歌单（后续） |
| Ctrl/Cmd K | 全局搜索面板 |
| Space | 播放/暂停 |
| ← / → | 快退/快进 5s |
| ↑ / ↓ | 音量 |
| L | 打开歌词 |
| F | 喜欢当前曲目 |
| M | 静音 |
| Alt 1/2/3 | 探索/搜索/音乐库 |
| Esc | 关闭播放页/命令面板 |

## 6. 响应式

- ≥1240：完整三栏。
- 1120–1240：右栏 300px，卡片 4 列。
- <1120：右栏隐藏，dock 右移贴边。
- <900：侧栏只有图标；播放页纵向堆叠。
- <720：侧栏隐藏；dock 简化为封面 + 控制 + 进度；标题栏隐藏历史按钮。

## 7. Windows 集成（规划）

| 能力 | 实现 |
|---|---|
| 自定义标题栏 | Tauri `decorations: false` + `data-tauri-drag-region` |
| Mica / Acrylic | `window-vibrancy`，Win11 Mica，Win10 Acrylic/纯色 |
| 窗口控制 | 最小化/最大化/关闭；后续 Snap Layout |
| 托盘 | 显示/隐藏、播放控制、退出 |
| SMTC | `windows` crate 创建 SystemMediaTransportControls，封面/标题/进度 |
| 媒体键 | SMTC 接管；global-shortcut 作为补充 |
| 通知 | 切歌/错误；默认关闭 |
| 窗口状态 | 记忆尺寸/位置/最大化，多显示器 clamp |
| 迷你播放器 | 独立 420×128 置顶窗口（前端已预览，Tauri 窗口待接入） |
| 单实例 | 二次启动唤回主窗 |
| 自动更新 | Tauri updater + 签名（后续） |

## 8. 反模式

- 不要把手机截图放进一个 390px 宽的“手机框”里。
- 不要把所有内容做成单列并加大量留白。
- 不要用手机式底部 tab + 手势作为唯一导航。
- 不要用大面积品牌红铺满列表；红色是强调色。
- 不要在滚动容器上使用 `backdrop-filter`。
- 不要为了“像”而复制作者的 Logo、图标或源码；用自绘资产建立同一套语言。

## 9. alpha42 实际界面后的调整

真机截图显示底部是**迷你播放器 + 4 图标底栏**，首页是纯黑大幅图片流。桌面版据此调整为：

- 左侧 76px 图标栏默认折叠，替代底部 4 图标；主页/分类/资料库/搜索。
- 右侧正在播放栏默认收起，需要时从标题栏打开；给主内容更多宽度。
- 主页采用双列大幅推荐卡 + 横向货架，保留真机的大图叙事。
- 播放器采用两栏：左侧玻璃反光封面，右侧标题/星标/歌词入口；点击封面进入全屏歌词模式。
- 资料库、搜索、详情按真机结构重排；详情背景全屏模糊，内容最大 980px。
- 迷你播放器改为单行胶囊 + 底部红色进度线，不再显示时间、音量、队列等次要控件。
- 保留桌面标题栏、窗口控制、鼠标 hover、键盘快捷键；这些是真机没有但桌面必须有的部分。

### 设置页桌面化

- 真机是整屏 sheet；桌面保留为居中的 980px 圆角 sheet，side rail 仍可导航。
- 顶栏 sticky，X 关闭回主页；内容滚动时标题与关闭按钮保持。
- 账户/分组/行卡沿用真机的圆角与红色开关；行的说明文字在桌面可完整展开。
- 设置页打开时隐藏迷你播放器，避免遮挡 sheet 底部（真机同样不显示迷你条）。
