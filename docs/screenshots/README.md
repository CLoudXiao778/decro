## 源版本参考

alpha42 真机截图只保存在本地 `docs/screenshots/apk/`，用于设计研究，**不随公开仓库发布**：包含第三方专辑封面、用户收听记录与真实歌词。设计结论见 `docs/apk-analysis.md` 与 `docs/style-audit.md`。

## 已知差异

- 真机首页/详情使用真实照片封面；原型使用生成式抽象封面，等待接入真实数据。
- 真机播放器为竖排单列；桌面版为两栏桌面布局，保留同一套封面、星标、波形、白色矩形播放键与歌词模式。
- 真机底栏是 4 个底部图标；桌面版改为左侧图标栏。
- 真机为纯黑深色；桌面原型额外提供浅色主题。
