# 风格一致性审计

对照对象：`Cirro-alpha42.APK` 真机运行截图 + 公开仓库 `ThripleQ/cirro` 的设计/动效源码。
对照版本：本仓库 0.1.0 前端原型（2026-11-08 校正后）。

> 关键发现：alpha42 的实际 UI 与公开仓库当前源码的 Android 界面并不完全一致。alpha42 更“纯黑 + 大图 + 玻璃”；公开仓库更接近另一条设计线。本审计以**真机截图**为准，源码只提供令牌与动效参数。
>
> 真机截图只保存在本地 `docs/screenshots/apk/`，因包含第三方专辑封面/用户数据/真实歌词，不随公开仓库发布。

## 2. 有意桌面化

| 真机 | 桌面 | 原因 |
|---|---|---|
| 底部 4 图标 + 迷你播放器 | 左侧图标栏 + 底部迷你播放器 | 桌面效率与横向空间 |
| 播放页竖向单列 | 封面左 / 标题与歌词右；歌词模式全宽 | 16:9 桌面，不放大手机比例 |
| 首页两张卡约占满屏宽 | 双列大幅卡 + 横向 5 张货架 | 1440 桌面密度 |
| 搜索/详情全宽 | 内容最大 980px 居中 | 阅读宽度与桌面留白 |
| 无标题栏 | 自定义桌面标题栏 | 窗口控制/搜索/主题 |
| 星标仅白描边 | 保留星标；桌面版有 hover 态 | 鼠标可发现性 |

## 3. 尚未对齐 / 已知偏差

| 项 | 说明 | 下一步 |
|---|---|---|
| 真实照片封面 | 原型使用生成式渐变封面 | 接入 API 后替换；保留暗角/模糊/玻璃 |
| 玻璃反射着色器 | 真机为运行时材质/反光；桌面用 CSS 宽高光带近似 | 后续可换 WebGL 材质，但默认保持轻量 |
| 详情返回逆动画 | 目前是 300ms 淡入/上移；真机从卡片/hero 返回 | 后续补 FLIP 逆动画 |

| 歌单详情星标 | 本地状态，不写回账号 | 接入 API 后落库 |

## 4. 视觉验收清单

- [x] 深色背景为纯黑，不是深灰。
- [x] 首页标题「主页」超大、左上；右上圆形头像。
- [x] 两张大幅推荐卡；标题/副标题压在底部渐变上。
- [x] 迷你播放器为单行胶囊，底部有红色进度线。
- [x] 播放键为白色圆角矩形，不是圆形。
- [x] 喜欢为星标，不是心形。
- [x] 播放器封面有斜向玻璃反光。
- [x] 播放器进度为波形 + 竖向 thumb。
- [x] 歌词模式是全屏歌词；当前行大号白色粗体，翻译小一号。
- [x] 详情页为全屏模糊封面 + 居中标题 + 玻璃曲目行。
- [x] 搜索聚焦后输入框置顶，红色 X，Cloud Music/资料库分段。
- [x] 资料库为 5 条整行入口 + 最近添加。
- [x] 共享封面从 dock 长到播放页；面板 clip 从 dock 矩形展开。
- [x] `prefers-reduced-motion` 降级。

## 5. 结论

2026-11-08 的真机截图推翻了最初基于公开源码的一些判断（尤其“卡片 + 底部三 tab”的印象）。校正后的桌面原型已经采用 alpha42 的真实语言：**纯黑、大图、星标、白色大播放键、波形、玻璃封面、全屏模糊详情、极简搜索**，同时把导航与播放器重排为桌面结构。

剩余最重要的两件事：

1. 接入真实封面后重新调校模糊、取色与玻璃反射；
2. 补详情/卡片的返回逆动画与逐字歌词。
